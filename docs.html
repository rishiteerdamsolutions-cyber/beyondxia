pRAG setup & user guide

Everything you need to run your personal RAG: what to prepare, how to connect Claude, and how to get answers from your own documents.

1. What you need

  • A computer to run pRAG on (setup details come with your access — request access here).
  • PDFs you have permission to use — your own notes, openly licensed books, or material your school has authorised. Never upload pirated or borrowed material.
  • A Claude API key (BYOK). Create one in Anthropic's console (console.anthropic.com) under your own account. API usage is billed by Anthropic to your key — check their pricing before heavy use.
  • Internet access — your questions and the matching passages are sent to the Claude API to generate answers.

2. Install pRAG

pRAG is currently shared directly with users and pilot schools. Contact us on WhatsApp or email to request access, and we'll send the installer plus setup help.

3. Add your PDFs

  1. Open pRAG and choose Add documents.
  2. Select one chapter or subject at a time — smaller, well-organised sets give better answers.
  3. Wait for indexing to finish before asking questions (large PDFs take longer).

4. Connect your Claude key

  1. Copy your API key from the Anthropic console.
  2. In pRAG, open Settings → Claude API key and paste it.
  3. Send a test question. If it answers with page references, you're connected.

Treat your key like a password — don't share screenshots containing it, and revoke it in the Anthropic console if it ever leaks.

5. Ask questions

Type your question in Ask mode. You'll get a concise answer plus the pages it came from — expand each reference and read the passage yourself before trusting important answers.

6. Voice explain mode

Press play on any answer or document section. pRAG explains it aloud like a real person, in plain words. Pause, replay, or slow down any part. Long documents may span multiple sessions — your place is saved per document set.

Troubleshooting

  • "Invalid API key" — re-copy the key from the Anthropic console; check for extra spaces.
  • Answers feel off-topic — narrow the document set to one chapter, and rephrase the question with terms from the book.
  • Slow indexing — split very large PDFs by chapter and index them separately.
  • Something else broken? — message us on WhatsApp (+91 95050 09699) with what you clicked and what you saw.

Honest limits

  • pRAG needs a Claude API key and internet — it is not an offline app.
  • It can make mistakes. Teachers and textbooks remain the authority.
  • It only knows what you upload — it won't answer from outside your documents.
