What we build

pRAG is the core product: a personal RAG (retrieval-augmented generation) app. You add documents you are allowed to use, connect your own Claude API key, and ask questions. pRAG finds the matching passages and Claude answers from them, with page references you can open and check. Voice mode explains an answer or a section aloud in plain words.

pRAG runs on the user's own computer. We do not host or receive users' documents or API keys. It is currently in early access: we share it directly with people and organisations who request access.

Kinkar is the first product built on pRAG: an AI recruiter workforce for US IT staffing. A staffing desk adds the job descriptions, client requirements, and notes it is allowed to use; Kinkar uses pRAG so Claude answers stay grounded in that material. See Kinkar.

How we use Claude

  • Claude, through the Claude API from Anthropic, is the only model pRAG and Kinkar use — for grounded answers and for voice explanations.
  • Users connect their own Anthropic API key, so their usage is billed by Anthropic to their account, not through us.
  • We build pRAG and Kinkar with Claude, and use the Claude API on our own company account for development and testing.
